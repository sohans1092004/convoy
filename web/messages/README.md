# Messages (next-intl)

- `en.json`: English, the source. Every key the UI uses lives here.
- `hi.json`: Hindi for the buyer journey. **Machine-drafted** (written by an AI assistant in P2, 2026-10-25) and
  **not yet reviewed by a native speaker**: treat it as a draft until a reviewer signs it off. Legal and money wording
  (deposit, refund, ceiling, cancellation) needs that review before any real buyer sees it.
- A key missing from `hi.json` falls back to English (i18n/request.ts), never to a blank.
- Strings still hard-coded in components (so not translatable yet) are listed in `reports/p2/i18n-untranslated.md`,
  generated by `node scripts/i18n-untranslated.mjs`.

The language is chosen with the English / हिन्दी switch in the header (cookie `NEXT_LOCALE`).
